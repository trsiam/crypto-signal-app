# Contributing Guide

This project is currently maintained by the project owner with AI-assisted development.

## Development Rules

- Follow the master blueprint as the source of truth.
- Work on one small task at a time.
- Do not commit broken code to the `main` branch.
- Test changes before committing them.
- Never commit API keys, passwords, tokens, or private configuration.
- Keep code simple, readable, and documented.
- Review AI-generated code before accepting it.
- Record important architecture or scope changes in the project documentation.

## Git Workflow

1. Create or update files.
2. Review changes with `git diff`.
3. Check the project with the relevant tests.
4. Stage the intended changes.
5. Create a clear commit message.
6. Push the commit to GitHub.

## Commit Message Examples

chore: configure project tooling
docs: update setup instructions
