# Crypto Signal Prediction Web App

A free, no-account crypto market analysis web application that will provide:

- Live crypto market data
- Technical indicators
- Rule-based signals
- Machine-learning predictions
- Confidence, expected move, volatility, signal, risk, and explanation
- Prediction history and outcome tracking
- Browser-local watchlists
- Anonymous browser alerts
- A private owner admin dashboard

## Project Status

Early development - Phase 0: Project Control.

## Core Principle

Build the transparent, rule-based, data-quality-aware system first.

Machine learning will only be added after the market-data pipeline, technical indicators, prediction history, backtesting, and safety controls are working correctly.

This application is intended to provide probability-based educational market analytics.

It will not guarantee profits, provide personalized financial advice, hold funds, connect wallets, request private keys, or execute trades.
